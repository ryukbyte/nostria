# Nostra - E-commerce Website

Nostra is a responsive e-commerce website developed using **HTML, CSS, and JavaScript**. The project focuses on creating a clean, responsive shopping experience with interactive features and client-side form validation.

## Features

* Responsive navigation bar
* Home page
* Collections page
* Contact Us page
* Responsive design for different screen sizes
* Contact form with validation
* Name, email, phone, and subject validation
* Radio buttons for preferred contact method
* Checkboxes for product interests
* Message character limit
* Submit button validation
* Success message after form submission
* Mobile-friendly navigation

## Pages

### Home

Introduction to the Nostra brand with featured content.

### Collections

Displays the available fashion collections and products.

### Contact Us

Allows users to submit their details and send an enquiry through the contact form.
